# Spring Module 1 - User Registration & Notification Service

## 📌 Overview

This project is a beginner-friendly Spring Boot application that demonstrates the fundamentals of Dependency Injection (DI) and Inversion of Control (IoC).

The application simulates a simple user registration process and sends a notification after successful registration using different notification service implementations.

---

## 🚀 Features

- User Registration
- Notification Service Interface
- Email Notification Implementation
- SMS Notification Implementation
- Dependency Injection using Spring
- Spring Boot Application Structure

## ▶️ Run the Project

### Clone the repository

```bash
git clone https://github.com/harisai-singuluri/springmodule1.git
```

### Navigate to the project

```bash
cd springmodule1
```

### Run using Maven

```bash
./mvnw spring-boot:run
```

Or run the application directly from IntelliJ IDEA.
